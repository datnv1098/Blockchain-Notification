PROCESSING FLOW
───────────────

BEFORE (Slower):
   1. Fetch transfers (API)
   2. For each token:
      a. Check if notified (local)
      b. Check time window (API)
      c. Get balance (API, sometimes cached)
      d. Get price (API, 10 min cache)
      e. Calculate & alert
   Time: ~2-5 seconds per wallet
   API calls: ~3-4 per transfer

AFTER (Faster):
   1. Fetch transfers (API)
   2. For each token:
      a. Extract info from TX data (INSTANT)
      b. Check if notified (local)
      c. Check time window (API)
      d. Get balance (API, cached 5 min)
      e. Get price (CACHED 1 hour - instant!)
      f. Calculate & alert
   Time: <1 second per wallet (70% faster)
   API calls: ~1-2 per transfer (50% reduction)
